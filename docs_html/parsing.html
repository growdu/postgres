raw_parser() 详解 (parser.c:42)

raw_parser(const char *str, RawParseMode mode)
返回 List<RawStmt>，包含 stmt / stmt_location / stmt_len
  • scanner_init() — 初始化 flex 词法扫描器，加载关键词表 ScanKeywords
  • parser_init() — 初始化 bison 语法解析器状态
  • base_yyparse(yyscanner) — 执行 bison 解析，填充 parsetree
  • scanner_finish() — 释放扫描器资源

RawParseMode 模式

  • RAW_PARSE_DEFAULT — 标准 SQL 解析（simple query 协议用这个）
  • RAW_PARSE_TYPE_NAME — 类型名解析（如 CREATE TABLE 列类型）
  • RAW_PARSE_PLPGSQL_EXPR / _ASSIGN* — PL/pgSQL 函数内表达式/赋值解析

词法分析器 (scan.l → scanner.c)

core_yylex()
核心词法函数，返回 token ID
  • 识别标识符、关键字、字符串常量的 token ID
  • 处理数字常量、运算符、标点符号
  • 自动去除注释（/* */ 和 --）
  • 将双引号标识符转为普通标识符
base_yylex()
parser.c:111 词法过滤器
  • 处理多 token 向前看（lookahead），保持 grammar LALR(1)
  • 将 UIDENT/USCONST 序列转换为 IDENT/SCONST
  • 处理 NOT NULL、FORMAT、TITLE 等多词 token
  • 转换 core_YYSTYPE 与 YYSTYPE 表示

语法解析器 (gram.y)

base_yyparse() — bison 生成，遵循 LALR(1) 语法
  • gram.y 定义全部 SQL 语法规则（SELECT/INSERT/UPDATE/DELETE/DDL/...）
  • 约 600+ 语法规则，深度嵌套的递归结构
  • 每个语法规则对应一个语义动作，产出对应 Node 类型
  • 结果类型为 RawStmt — 包裹 stmt + 位置信息
RawStmt 结构
  • Node *stmt — 实际语法树节点（SelectStmt / InsertStmt / ...）
  • int stmt_location — 在原始 SQL 中的字节偏移
  • int stmt_len — 语句长度（-1 表示到字符串结尾）

输出：List<RawStmt>

List<RawStmt> — 一个 SQL 字符串可能包含多条语句
  • 多条语句以分号分隔，每条对应一个 RawStmt
  • RawStmt.stmt 是未经语义分析的原生态语法树
  • 不含数据类型、表结构、列引用解析信息
  • 作为 pg_parse_query 的最终产出，交给下一阶段

调用入口

pg_parse_query(query_string) postgres.c:604
  • TRACE_POSTGRESQL_QUERY_PARSE_START / DONE 追踪点
  • log_parser_stats 时调用 ResetUsage/ShowUsage
  • DEBUG_NODE_TESTS_ENABLED 时可做 copyObject / outfuncs/readfuncs 校验
  • 仅做解析，不做任何语义判断（即使处于 abort 事务状态也会解析）
