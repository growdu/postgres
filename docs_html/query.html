执行器

核心入口：exec_simple_query (postgres.c:1012)

事务控制

  • start_xact_command() 开启事务命令
  • use_implicit_block 多语句自动开启隐式事务块
  • finish_xact_command() 结束事务命令
  • CommandCounterIncrement() 命令计数器递增

每条语句的处理循环

  • pg_parse_query() → 解析 SQL 字符串为 RawStmt 列表
  • analyze_requires_snapshot() 判断是否需要快照
  • pg_analyze_and_rewrite_fixedparams() → Query
  • pg_plan_queries() → PlannedStmt
  • CreatePortal() 创建 Portal (游标)
  • PortalStart() 启动 Portal
  • PortalRun() 执行查询

状态检查

  • abort 状态只允许 COMMIT/ABORT
  • CHECK_FOR_INTERRUPTS() 在各阶段检查信号
  • 多语句间重置 statement timeout

输出控制

  • CreateCommandTag() 生成命令标签
  • DestReceiver 决定结果发送目标
  • EndCommand() 发送命令完成消息
  • check_log_duration() 日志记录耗时
