三种 parse_analyze 变体

parse_analyze_fixedparams

analyze.c:105
参数类型已知（如 prepared statement）直接使用
  • paramTypes[] 数组由调用者提供
  • 最简单，无类型推断

parse_analyze_varparams

analyze.c:145
参数类型需从上下文推断（最常用）
  • 用于 simple query 协议（SELECT * FROM t WHERE id = $1）
  • check_variable_parameters() 验证推断结果
  • 遇到 UNKNOWNOID 或 InvalidOid 则报错

parse_analyze_withcb

analyze.c:186
自定义 ParserSetupHook 解析参数
  • 允许外部扩展介入参数类型解析
  • 如某些 FDW 或定制化场景

ParseState — 分析上下文

ParseState — 贯穿整个分析阶段的上下文结构
  • p_sourcetext — 原始 SQL 字符串（用于错误定位）
  • p_queryEnv — 查询环境（搜索路径、DDL 配置等）
  • p_param_types[] / p_num_params — 参数类型信息
  • p_rtable — 范围表（RangeTblEntry 列表，记录 FROM 子句）
  • p_joinlist — JOIN 构建过程中的临时结构
  • p_namespace — 当前名字空间（表/视图别名解析）
  • p_exprsubtype — 表达式类型（用于区分不同解析上下文）

transformTopLevelStmt() (analyze.c:249)

transformTopLevelStmt(ParseState *pstate, RawStmt *parseTree)
调用 transformOptionalSelectInto 处理 SELECT INTO 转换
  • 顶层入口，设置 stmt_location 和 stmt_len 到结果 Query
  • 处理 SELECT ... INTO → CREATE TABLE AS 转换
  • 调用链：transformTopLevelStmt → transformOptionalSelectInto → transformStmt

transformStmt() — 核心递归变换

transformStmt() — analyze.c
  • 根据 stmt 类型分发到具体 transform 函数
  • transformSelectStmt() — SELECT 处理
  • transformInsertStmt() — INSERT 处理
  • transformUpdateStmt() — UPDATE 处理
  • transformDeleteStmt() — DELETE 处理
  • transformCreateStmt() — DDL 处理
transformSelectStmt 分支
  • transformTargetList() — SELECT 列表解析
  • transformFromClause() — FROM 子句解析
  • transformWhereClause() — WHERE 条件解析
  • transformGroupClause() — GROUP BY
  • transformWindowClause() — WINDOW 子句
  • transformSortClause() — ORDER BY
  • transformLimitClause() — LIMIT

语义分析做了什么

  • 表/列解析：将标识符解析为具体表、列、函数，验证是否存在
  • 类型推导：推断 $1 等参数的具体数据类型
  • 权限检查：验证用户是否有权访问引用的对象
  • 语法糖展开：SELECT * 展开为具体列，DEFAULT 表达式求值
  • 语义校验：JOIN 条件完整性、聚合函数合法性、GROUP BY 验证
  • 查询重写规则引用：建立规则查找的内部数据结构
  • CTE/子查询处理：WITH RECURSIVE 展开，flatten 之子查询

输出：Query

Query — 语义树，包含 cmdType / rtable / targetList / jointree / ...
  • commandType — CMD_SELECT / CMD_INSERT / CMD_UPDATE / CMD_DELETE / CMD_UTILITY
  • querySource — QSRC_ORIGINAL（来自解析器）
  • canSetTag — 是否可设置命令标签
  • rtable — 范围表（所有引用的表/视图）
  • targetList — 目标列列表
  • jointree — JOIN 树结构
  • groupBy / having — GROUP BY 及 HAVING
  • sortClause — ORDER BY
  • limitOffset / limitCount — LIMIT/OFFSET
  • returningList — RETURNING 子句

附加处理

JumbleQuery(query) — 计算 queryId 用于 pg_stat_statements
  • 生成查询的归一化指纹（去除 literals 参数化）
  • 归一化后相同结构的查询有相同 queryId
post_parse_analyze_hook — 可扩展钩子
  • 在 parse_analyze 完成之后、返回之前调用
  • 允许扩展（如 pg_stat_statements）注入处理逻辑
