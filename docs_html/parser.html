内部处理流程

  • scanner_init() → 初始化 flex 词法分析器 (scan.l)
  • base_yyparse() → 调用 bison 解析器 (gram.y)
  • base_yylex() → 词法过滤器，处理多 token 向前看和大小写转换
  • gram.y 定义所有 SQL 语法规则，产出 RawStmt 节点
  • RAW_PARSE_DEFAULT 模式：标准 SQL 解析；还支持 TYPE_NAME / PL/PGSQL_EXPR 等特殊模式

三种 parse_analyze 变体

  • parse_analyze_fixedparams — 参数类型已知（如 prepared statement）
  • parse_analyze_varparams — 参数类型需从上下文推断（最常用，如 simple query）
  • parse_analyze_withcb — 自定义解析回调（如某些扩展场景）

重写结果

  • 一个输入 Query 可能展开为多个输出 Query（规则展开）
  • CMD_UTILITY 语句跳过重写，直接返回
  • RIR (Rule Instead of Row) 处理每个-qualified 行级规则
  • 重写后保留 queryId 用于 pg_stat_statements
